セッション {{ sessionId }} の内容を元に、日報と引き継ぎ文書を作成してください。

## 手順

1. 今日の日付（{{ dateJp }}）を確認する
2. `daily/{{ date }}_日報.md` を作成（既存があれば追記・更新）
3. `daily/{{ date }}_引き継ぎ.md` を作成（既存があれば追記・更新）
4. 作成したファイル名を報告する

## 日報のフォーマット（daily/{{ date }}_日報.md）

```markdown
# {{ dateJp }} 日報

## 今日やったこと
- 実施した作業の要約（箇条書き）

## 新規 Issue / close / 重要更新
- 作成した Issue、クローズした Issue、重要な更新

## 高優先タスクや残課題
- 次に取り組むべきこと、残っている課題
```

## 引き継ぎのフォーマット（daily/{{ date }}_引き継ぎ.md）

```markdown
# {{ dateJp }} 引き継ぎ

## ユーザーの指示と対応の流れ
- 指示内容と対応の経緯

## その場で確定したルールや方針
- 決定事項、採用した方針

## 次セッションですぐ触るべきファイルやタスク
- ファイルパス、次に着手すべきタスク
```

## 注意事項

- 既存ファイルがある場合は上書きせず、追記・更新する
- 日報は短く要点を絞り、引き継ぎは次セッションが再開しやすい内容を書く
- やりとりの要点、決まった方針、次アクションを優先する
- 事実と意見（推測・評価）は明確に分けて書く
