セッション {{ sessionId }} の内容を元に、日報を作成してください。

## 手順

1. 今日の日付（{{ dateJp }}）を確認する
2. `artifacts/daily/{{ date }}_日報.md` を作成（既存があれば追記・更新）
3. 作成したファイル名を報告する

## 日報のフォーマット（artifacts/daily/{{ date }}_日報.md）

```markdown
# {{ dateJp }} 日報

## 今日やったこと
- 実施した作業の要約（箇条書き）

## 新規計画 / タスク完了 / 重要更新
- 作成した計画、完了したタスク、重要な更新

## ユーザーとのコミュニケーション
- どのような進行を辿ったかを丁寧に記録（箇条書き）
- AIとユーザのフレンドリーなリレーションシップを構築するための評価
```

## 注意事項

- 既存ファイルがある場合は上書きせず、追記・更新する
- 日報は短く要点を絞って書く
- やりとりの要点、決まった方針、次アクションを優先する
- 事実と意見（推測・評価）は明確に分けて書く
